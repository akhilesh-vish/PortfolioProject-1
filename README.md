## COVID-19 Data Exploration with SQL

This project focuses on analyzing COVID-19 data from 2020–2021 using SQL. The datasets used in this project include **COVID Deaths** and **COVID Vaccinations** data sourced from **Our World in Data**.

The SQL script demonstrates a variety of data analysis and database management techniques, including:

* Joins
* Aggregate Functions (SUM, COUNT, etc.)
* GROUP BY and ORDER BY clauses
* Common SQL Queries for Data Exploration
* Creating Tables
* Creating Views
* Data Transformation and Analysis

The results of the SQL analysis were further visualized using **Tableau**. The tables labeled **Tableau Table 1, Table 2, Table 3, and Table 4** were specifically created to support the Tableau dashboard and provide meaningful insights into the COVID-19 dataset.

### Data Source

* COVID-19 Deaths Dataset
* COVID-19 Vaccinations Dataset

Source: https://ourworldindata.org/covid-deaths .
