This is a simple SQL project in which the Covid data from 2020-2021 is used.

Both the Covid Deaths and Covid Vaccination data is taken from ourworldindata.org.

In the Attached SQL file verious SQL operations are performed on the data.

The Operations include Join, Group by, Order by, SUM, Create Tabel, Create View, ETC..

The Tableau Tables 1,2,3 & 4 are part of the data used in the created Tableau Dashboard.
